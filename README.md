# chess-llm

Fine-tune Qwen3-4B on Stockfish-labeled chess (QLoRA SFT, optional GRPO), then play it in a local Matrix-style UI.

The 4B model stays on your GPU. The Next.js app is deployable later; do **not** host the model on Vercel.

## What is in this repo

Source, configs, tests, and the UI. **Not** included (too large / machine-local):

- `data/*.parquet` — generated by the sampler
- `outputs/` — LoRA adapters and train logs
- `web/.env.local` — copy from `web/.env.example`

## Hardware

Tested on an RTX 5060 Ti 16GB (Blackwell `sm_120`) + 32GB RAM, Windows + WSL2 Ubuntu.

WSL memory cap: `%USERPROFILE%\.wslconfig` (16GB minimum, 20–24GB better):

```
[wsl2]
memory=24GB
swap=8GB
```

Then `wsl --shutdown` from PowerShell. Do **not** install a Linux NVIDIA driver inside WSL.

## One-time WSL env

Reuse a PyTorch **cu128** conda env or create `chess_llm`.

Do **not** `pip install unsloth` unconstrained — it tries to downgrade torch below 2.12 and breaks Blackwell.

```bash
cd /path/to/chess_game
source ~/miniforge3/etc/profile.d/conda.sh
conda activate llm_gpu          # or: bash scripts/setup_wsl.sh
pip install -e ".[dev]"
bash scripts/install_unsloth_blackwell.sh
python scripts/gpu_smoke.py
```

Smoke test must print a working CUDA build (`cuda=12.8` or newer) and `available=True`.

## Data

Streams [Lichess/chess-position-evaluations](https://huggingface.co/datasets/Lichess/chess-position-evaluations). Does **not** download the full dump.

```bash
python -m chess_llm.data.sample --out-dir data --min-depth 20 --sample-mod 1
```

Writes `data/train.parquet` (2M), `val.parquet` (20k), `test.parquet` (20k), `rl.parquet` (50k).

## Train

Default SFT is **4,000 steps** of QLoRA (a slice of the 2M pack, ~5–10h on a 16GB card), then short GRPO. Checkpoints go to `$HOME/chess_outputs` in WSL.

```bash
# smoke
python -m chess_llm.train.sft --config configs/sft.yaml --max-samples 32
python -m chess_llm.train.grpo --config configs/grpo.yaml --max-samples 8 --max-steps 1

# intended run (WSL)
bash scripts/train_full.sh
```

OOM knobs: `per_device_train_batch_size`, `lora_r`, `max_seq_length`, `num_generations` in `configs/`. If GRPO OOMs: `python -m chess_llm.train.dpo --config configs/dpo.yaml`.

Windows unattended helper (keeps the PC awake, resumes from the last complete checkpoint): `scripts/watchdog.ps1`.

## Eval + CLI

```bash
python -m chess_llm.eval.metrics --data data/test.parquet --limit 2000 --adapter outputs/grpo
python -m chess_llm.infer --fen "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1"
```

## Play (Matrix UI)

```bash
python -m chess_llm.serve   # WSL + GPU; stub moves if no adapters yet
cd web && npm install && npm run dev
```

http://localhost:3000 — set `NEXT_PUBLIC_INFERENCE_URL` in `web/.env.local` if you change the API port.
